# 股票量化交易系统

> 一个为编程零基础小白设计的 A 股量化交易回测系统。双击运行即可体验完整的策略回测流程。

## 系统简介

本系统使用 Python 编写，能自动获取股票数据、运行交易策略、计算收益指标、生成可视化图表。你不需要任何编程基础，只需要修改配置文件中的参数，就能测试不同的交易策略。

### 系统能做什么？

- 自动获取股票行情数据（支持同花顺 iFinD 真实数据 + 内置模拟数据）
- 计算常用技术指标（均线、MACD、RSI、布林带）
- 运行交易策略，自动生成买卖信号
- 模拟完整交易过程，计算手续费、印花税、滑点
- 统计收益指标（总收益率、年化收益率、最大回撤、夏普比率、胜率）
- 生成专业可视化图表（股价走势、买卖点、资金曲线、MACD、成交量）

## 配置说明（config.py）

这是你唯一需要修改的文件。所有参数都有中文注释说明。

### 1. 数据源配置

```python
# iFinD Token（获取真实数据需要，留空则自动使用模拟数据）
IFIND_AUTH_TOKEN = ""

# 股票代码（A 股名称或代码均可）
STOCK_CODE = "贵州茅台"       # 也可以用 "600519.SH"

# 回测时间范围
START_DATE = "2024-01-01"
END_DATE = "2025-12-31"
```

### 2. 策略参数

```python
# 双均线策略：短期均线上穿长期均线买入，下穿卖出
SHORT_MA_PERIOD = 5     # 短期均线天数
LONG_MA_PERIOD = 20     # 长期均线天数
```

### 3. 回测参数

```python
INITIAL_CAPITAL = 100000.0  # 初始资金（元）
COMMISSION_RATE = 0.0003    # 手续费率（万分之三）
STAMP_TAX_RATE = 0.001      # 印花税率（千分之一，仅卖出）
SLIPPAGE = 0.001            # 滑点（千分之一）
```

## 如何获取 iFinD 真实数据 Token

没有 Token 也能用！系统会自动使用模拟数据运行。如果你想获取真实股票数据：

1. 访问同花顺 iFinD MCP 官网：https://mcp.51ifind.com/
2. 注册/登录账号
3. 进入「个人中心 → 密钥」页面
4. 复制你的 API Key
5. 粘贴到 `config.py` 的 `IFIND_AUTH_TOKEN = "你的Key"` 中
6. 重新运行程序，系统会自动切换到真实数据模式

## 回测结果解读

运行完成后，控制台会输出回测摘要：

```
==================================================
           回测结果摘要
==================================================
  初始资金:       ¥    100,000.00
  最终资金:       ¥    119,259.55
  总收益率:                19.26%
  年化收益率:               8.86%
  最大回撤:                23.34%
  夏普比率:                 0.37
--------------------------------------------------
  总交易次数:                 15
  盈利次数:                    6
  亏损次数:                    9
  胜率:                    40.00%
  平均每笔盈亏:    ¥     1,319.04
==================================================
```

### 指标含义

| 指标 | 含义 | 参考标准 |
|:---|:---|:---|
| 总收益率 | 整个回测期间的盈利百分比 | 正数表示赚钱 |
| 年化收益率 | 折算成每年的收益率 | >8% 不错，>15% 优秀 |
| 最大回撤 | 从最高点到最低点的最大跌幅 | 越小越好，<20% 较好 |
| 夏普比率 | 每承担1单位风险获得的超额收益 | >1 较好，>2 优秀 |
| 胜率 | 盈利交易占总交易的比例 | >50% 不错 |
| 平均每笔盈亏 | 每笔交易平均赚/亏多少钱 | 正数表示整体盈利 |

### 图表说明

生成的 `backtest_result.png` 包含四个子图：

1. **股价 + 均线 + 买卖点**：红色三角是买入点，绿色倒三角是卖出点
2. **资金曲线**：蓝色线是你的总资产变化，红色阴影是回撤区域
3. **MACD 指标**：红绿柱表示多空力量变化
4. **成交量**：红柱是上涨日成交量，绿柱是下跌日成交量

修改 `main.py` 中的策略创建部分：
```python

strategy = MACDStrategy()
```

### 更换回测时间段

修改 `config.py`：
```python
START_DATE = "2023-01-01"
END_DATE = "2025-06-30"
```

### 清除数据缓存重新获取

删除 `data_cache` 文件夹，或在 Python 中运行：
```python

```

## 技术指标说明

| 指标 | 全称 | 用途 |
|:---|:---|:---|
| MA | 移动平均线 | 判断趋势方向，均线交叉产生买卖信号 |
| EMA | 指数移动平均线 | 比 MA 更灵敏，重视近期价格 |
| MACD | 异同移动平均线 | 判断趋势强弱和转折点 |
| RSI | 相对强弱指数 | >70 超买（可能跌），<30 超卖（可能涨） |
| 布林带 | Bollinger Bands | 价格触及上轨可能回调，触及下轨可能反弹 |

## 常见问题

### Q: 运行报错 "No module named xxx"
A: 依赖包未安装。运行 `pip install -r requirements.txt`，或直接双击 `run.bat` 自动安装。

### Q: 图表中文显示为方框
A: 系统未找到中文字体。确保 Windows 系统安装了「黑体」(SimHei) 字体，一般默认都有。

### Q: iFinD 数据获取失败
A: 检查 `config.py` 中的 `IFIND_AUTH_TOKEN` 是否正确填写。如果暂时没有 Token，系统会自动使用模拟数据。

### Q: 如何查看交易明细
A: 程序运行时会在控制台打印每笔交易的日期、价格、数量、费用和盈亏。

### Q: 模拟数据和真实数据有什么区别
A: 模拟数据是用数学模型生成的随机走势，用于学习和测试系统功能。真实数据来自同花顺 iFinD，反映实际市场行情。策略逻辑、回测引擎、指标计算在两种模式下完全相同。

## 进阶开发指南

如果你想在此基础上开发更多功能，可以参考以下思路：

### 添加新策略
在 `strategy.py` 中创建新类，实现 `generate_signals(df)` 方法，返回带有 `signal` 列的 DataFrame。

### 添加新指标
在 `indicators.py` 中添加新的计算函数，然后在 `add_indicators()` 中调用。

### 优化回测引擎
在 `backtest.py` 的 `Backtest.run()` 方法中，可以添加：
- 仓位管理（不满仓买入）
- 止损止盈逻辑
- 多股票组合回测

### 对比多个策略
修改 `main.py`，同时运行多个策略，对比它们的收益指标。
